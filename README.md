# Kinforge Family History

**Research-grade, local-first genealogy software**

Kinforge Family History is a local-first genealogy and family history program built for serious research, source-based conclusions, long-term data durability, and strong user control.

## Goals

- Local-first by default
- No silent network calls, no telemetry, no cloud dependency
- Research-grade citation and evidence support
- Strong backup and upgrade safety
- Structured people, relationships, events, places, sources, and citations
- Extensible architecture without breaking the core model
- Single-user-first, with room for carefully controlled future expansion

## Core principles

- Data protection first
- Explicit, reviewable upgrades and migrations
- Strong validation and typed domain modeling
- Clear separation between core, storage, app, UI, reports, and import/export
- No throwaway prototype architecture
